Do you want readers to get more out of your RPC's Hazard Types? Do you want to use a fancy esoteric hazard icon, but [http://rpcauthority.wikidot.com/component-hazards-guide the old hazards component] doesn't support it? There's a new way to add hazard icons that does everything you need with a little more work.

[[# code]]

Here's the basic code:
> @@[[div class="manual-hazards"]]@@
> [[span style="background-color:green;color:white;"]]{TITLE (usually "Hazard Types" or "Additional Properties")}[[/span]]:
> @@* [[@@image [[span style="background-color:green;color:white;"]]{HAZARD ICON URL}[[/span]]@@]][[span]]@@[[span style="background-color:green;color:white;"]]{HAZARD NAME}[[/span]]@@[[/span]]@@
> @@* [[@@image [[span style="background-color:green;color:white;"]]{HAZARD ICON URL}[[/span]]@@]][[span]]@@[[span style="background-color:green;color:white;"]]{HAZARD NAME}[[/span]]@@[[/span]]@@
> @@* [[@@image [[span style="background-color:green;color:white;"]]{HAZARD ICON URL}[[/span]]@@]][[span]]@@[[span style="background-color:green;color:white;"]]{HAZARD NAME}[[/span]]@@[[/span]]@@
> @@[[/div]]@@

Repeat the hazard line for however many hazards as you need. Be sure not to leave any blank lines in the hazards div. The title is optional; remove its line to leave the icons on their own.

As you can see, the code is rather precise, so if formatting gives you trouble, this might not be for you. If you like to copy-paste, the [#hazards-palette hazards palette] at the bottom of the page will make writing these hazard blocks fast and easy.

----

++ How to: Basic example [[# basic-example]]

Say our anomaly turns invisible when touched. With the old hazards component, Invisibility would always display first due to the internal order of hazards, even if you specified otherwise. With the new system, we can do this:
[[div class="miniBlockquote"]]
> @@[[div class="manual-hazards"]]@@
> Hazard Types:
> @@* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-contact.png]][[span]]Contact[[/span]]@@
> @@* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-invisibility.png]][[span]]Invisibility[[/span]]@@
> @@[[/div]]@@
[[/div]]

Which gives us:
[[div class="content-panel"]]
[[div class="manual-hazards"]]
Hazard Types:
* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-contact.png]][[span]]Contact[[/span]]
* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-invisibility.png]][[span]]Invisibility[[/span]]
[[/div]]
[[/div]]

This might seem minor, but it can really add up as hazards accumulate. You'd be surprised how much you can communicate from the outset with only a set of well-ordered hazards. In the default order, the same hazards could just confuse.

++ How to: Separate "Additional Properties" [[# additional-properties]]

To create a hazard block with a separate properties section, you must add a second @@[[div class="manual-hazards"]]@@; they don't combine into one.

[[div class="miniBlockquote"]]
> @@[[div class="manual-hazards"]]@@
> Hazard Types:
> @@* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-contact.png]][[span]]Contact[[/span]]@@
> @@* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-invisibility.png]][[span]]Invisibility[[/span]]@@
> @@[[/div]]@@
> 
> @@[[div class="manual-hazards"]]@@
> Additional Properties:
> @@* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-animated.png]][[span]]Animated[[/span]]@@
> @@* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-organic.png]][[span]]Organic[[/span]]@@
> @@[[/div]]@@
[[/div]]

This gives us:
[[div class="content-panel"]]
[[div class="manual-hazards"]]
Hazard Types:
* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-contact.png]][[span]]Contact[[/span]]
* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-invisibility.png]][[span]]Invisibility[[/span]]
[[/div]]

[[div class="manual-hazards"]]
Additional Properties:
* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-animated.png]][[span]]Animated[[/span]]
* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-organic.png]][[span]]Organic[[/span]]
[[/div]]
[[/div]]

++ How to: Enable top spacing [[# top-spacing]]

If you wish to recreate the "top-spacing" attribute of the old hazards component, it's easy.

Instead of:
> @@[[div class="manual-hazards"]]@@

Use this:
> @@[[div class="manual-hazards" style="clear: both;"]]@@

Here's how it looks in action:
[[div class="content-panel"]]
[[f<image https://rpcauthority.wdfiles.com/local--files/component:icons/alpha-white.png]]

**Registered Phenomena Code:** XXX

**Object Class:** Alpha-White

[[div class="manual-hazards" style="clear: both;"]]
Hazard Types:
* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-contact.png]][[span]]Contact[[/span]]
* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-invisibility.png]][[span]]Invisibility[[/span]]
[[/div]]
[[/div]]

Compare to how it would look otherwise:
[[div class="content-panel"]]
[[f<image https://rpcauthority.wdfiles.com/local--files/component:icons/alpha-white.png]]

**Registered Phenomena Code:** XXX

**Object Class:** Alpha-White

[[div class="manual-hazards"]]
Hazard Types:
* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-contact.png]][[span]]Contact[[/span]]
* [[image http://rpcauthority.wdfiles.com/local--files/component:icons/h-invisibility.png]][[span]]Invisibility[[/span]]
[[/div]]
[[/div]]

If you use multiple hazards divs back-to-back (e.g. for a separate properties section), you only need to add this code to the first, whatever it may be.

As this example demonstrates, the hazards system is receptive to custom CSS for advanced users.

++ How to: Blue hazards [[# blue-hazards]]

Blue "updated" hazard icons, a la [[*user MrPines]], are possible with this system.
[[div class="miniBlockquote"]]
> @@[[div class="manual-hazards"]]@@
> Hazard Types:
> @@* [[image http://rpcsandbox.wikidot.com/local--files/mrpines/h-memory-alteration-2.png class="blue"]][[span]]Memory Alteration[[/span]]@@
> @@[[/div]]@@
[[/div]]

This gives us:
[[div class="content-panel"]]
[[div class="manual-hazards"]]
Hazard Types:
* [[image http://rpcsandbox.wikidot.com/local--files/mrpines/h-memory-alteration-2.png class="blue"]][[span]]Memory Alteration[[/span]]
[[/div]]
[[/div]]

The important part is adding class="blue" to the end of the image, which recolors the tooltip. Note that the blue icon still has to be created manually.
