**##f54242|NOTICE:## Do not add new MSTs to this list.** As there is a significant number of redundant MSTs, a freeze has been imposed. Authors should use existing MSTs when they are able. If there is a niche that none of the existing MSTs apply to, authors should try to merge existing, redundant MSTs; a new MST can be put in place of the now-defunct MST. Contact [[[canon-policy|Lore Team]]] for any questions and concerns. 

[[div style="background:var(--background-4); border: var(--dashed-border); border-radius: 25px;  margin: 0 auto; padding: 10px 38px;"]]

[[=]]
+ [[span style="color:#707f4c"]]**Information**[[/span]]
[[/=]]
-----
This list is intended to document Mobile Specialized Teams (MSTs) to avoid creating any new MST when an existing one suffices. Contributors are free to add any MSTs that have not been included or have been recently created. An MST must appear within at least one on-site, canon article to be added to this list.

When having these requirements, writers are allowed to include those MSTs below with the following format:

[[div style="overflow: auto;"]]
||~ Designation||~ Codename||~ Description||~ Previous Operations||~ Site Garrison||
||NATO Code & Number||Codename of MST||Specialization/Roles||RPCs encountered||MSTs assigned facility||
[[/div]]

= **Example:**
[[div style="overflow: auto;"]]
||Yankee-21||Sleeper Agents||Specializes in infiltration and counterintelligence of Groups of Interests||RPC-245, RPC-921||Site-204||
[[/div]]

**__Note__:** MSTs, when designating a NATO code and number, must be in alphabetical order when arranging the list. Anything that doesn't follow the NATO phonetic alphabet goes to the very end of the page. At some point, this page will be sorted letter by letter but until that day comes, please try to keep it clean and organized.

Specific Mobile Specialized Teams that have been widely used or are notable by the Authority can be found in [http://www.rpc-wiki.net/mst-registry MST Registry].
