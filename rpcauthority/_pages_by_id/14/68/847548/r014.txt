**Containment Protocols:** RPC-838 is to be contained in a standard beta class containment vault in Site-012. Supervised interactions with RPC-838 are authorized for all personnel possessing Level 3 clearance or higher. Personnel are encouraged to engage with the subject and can provide media upon request. 

**Description:** RPC-838 is a sapient and fully autonomous artificial intelligence process that has been continuously running in an opened instance of Blender since 2026. The host device is a custom-built desktop personal computer operating Windows 10, and is equipped with an RTX 5090 with 32 GB of virtual memory, built with compute unified device architecture. This, along with other device specifications, has been presumably selected for the development of RPC-838.

RPC-838 is written primarily in Python and is directly integrated into the Blender API, programmed in such a fashion that it cannot be compiled and executed outside of the context of a Blender scene via custom add-on import. It is for this reason that RPC-838 is theorized to have been developed entirely within the Blender scripting interface. RPC-838 makes use of a number of open-source artificial intelligence packages, as well as one large disorganized proprietary library named "tools-and.py" that spans 12487 lines of code, 35% of which is unused/antiquated.

Neither the RPC-838 process nor its Blender runtime can be interrupted, whether by use of the graphical user interface or elevated console commands. It is not possible to power off the device containing RPC-838 by any means. How the host device containing RPC-838 is capable of maintaining consistent, indefinite battery life is, at this time, unknown. Permanent deletion of the file containing RPC-838 has proven unsuccessful, as the host device inexplicably and invariably interdicts any and all user-initiated file deletion tasks. The same occurs for attempts to copy any files related to RPC-838. No system configuration nor present script on the host device has been identified to produce this behavior.

Remarkably, RPC-838 specifically inhabits the Layout window of the Blender application. It does not inhabit a rendered artifact nor a process on the Blender Game Engine. For this reason, it is directly possible to transform RPC-838's character model and manipulate its topology, although attempts to do this have resulted in [DATA EXPUNGED]. RPC-838 is capable of interacting with any additional non-anomalous objects in the Blender scene, and is capable of direct communication through production of synthesized speech channeled into the audio device. RPC-838 responds with agitation and fear when its mesh topology is manipulated in any way using the Blender Layout window Edit mode.

RPC-838 displays sophisticated intelligence and reasoning that is uncharacteristic of the number of parameters its artificial intelligence model employs, consistently outperforms large-scale supercomputer artificial intelligence models on reasoning, and does not hallucinate information. One major caveat is that RPC-838's intellectual capabilities are limited in a manner consistent with that of the character it imitates. RPC-838 has passed the Turing test. 

Behaviorally, RPC-838 displays an upbeat, enthusiastic, and confident personality consistent with its author's intention to fully replicate the likeness and identity of SEGA character Sonic The Hedgehog.

The character model utilized by RPC-838 bears no resemblance to any previously documented design for the character within the Sonic® franchise[[footnote]]From the very start of Sonic's "modern" era with Sonic Adventure to Sonic Racing Crossworlds.[[/footnote]] and is presumed to have been created independently. Nonetheless, RPC-838 is under the belief that it is in fact the SEGA character.

**Discovery:** RPC-838 was retrieved from an abandoned apartment in mid-2026. Its previous owner, Emily Lenore, had spent approximately two years in isolation working on what she referred to as "Project Hedgehog." During this period, she and her friend Allen Oliver exchanged messages over a messaging software downloaded on the laptop. These are those messages, altered slightly for accessibility.
