[[toc]]

> = **How to use includes**
> 
> Most components require use of an include module. It is usually easiest to copy the code from an article that uses it and modify it to what you need.
> 
> You can read the official Wikidot guide [[[https://www.wikidot.com/doc-wiki-syntax:include|here]]].

> = **How to use themes**
> 
> Place this code at the top of your article and plug in the URL
> 
>> [[module CSS]]
>> @import url(https://rpcauthority.wdfiles.com/local--code/component:example-theme/1);
>> [[/module]]

[[div class="content-panel"]]
**Mobile Container** by [[*user Jokezm]]

A module and div to help your CSS keep its structure and not overflow on mobile. You can also wrap them around components and tables.

[[collapsible show="+ Preview" hide="- Preview"]]

------

[[include component:image-block name=http://rpcsandbox.wdfiles.com/local--files/mobile-contianer/Withcontain.jpg|align=center|width=300px|caption=With mobile-container.]]

------

[[include component:image-block name=http://rpcsandbox.wdfiles.com/local--files/mobile-contianer/Withoutcontain.jpg|align=center|width=300px|caption=Without mobile-container.]]

------

[[/collapsible]]

Code: 
> [[module CSS]]
> @media screen and (max-width: 480px) {
> @@ @@ .mobile-container {
> @@ @@ @@ @@  width: 100%;
> @@ @@ @@ @@ font-size: 0.8em;
> @@ @@ @@ @@  padding: 0;
> @@ @@ @@ @@  margin: 0;
> @@ @@ }
> }
> [[/module]]

(Wrap this around your CSS/table/component)
> @@[[div class="mobile-container"]]@@
