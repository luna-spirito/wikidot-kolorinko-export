+ CSS Theme

Currently, due to our lack of knowledge regarding CSS coding, this site uses the [https://scp-wiki.wikidot.com/theme:site| Sigma-10 theme], the default CSS used to style the [https://scp-wiki.wikidot.com| SCP Wiki], as its base theme. The theme was originally created by [[*user Aelanna]] under the name Sigma-9 and is presently maintained by the SCP Wiki Technical Team.

This theme is available under the wiki's [https://creativecommons.org/licenses/by-sa/3.0/| Creative Commons Attribution-ShareAlike 3.0 license (CC-BY-SA)].

We hope that, in the near future, ADR will have its own custom CSS theme. Feel free to [[[main:contact|contact us]]] if you wish to help out.
